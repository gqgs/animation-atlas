01 / REFERENCE SCENES · VORTEX-1

Examples library

Every example executes on your GPU from its generator, parameters and seed. The Recursive Vortex is the default. Open an example to materialize its scene directly from a shareable URL fragment.

Six distinct presets of one engine kernel, not six separately implemented game engines. The runtime and schema are versioned; more behavior kernels and playable examples can be added without changing the URL contract.
SOURCE-FIRST ANIMATION

The scene is the program input.

The page renders a procedural vortex using WebGL2. No raster video, inference service, asset CDN, dynamic imports, account, or API calls are needed. The page includes the executable engine. Encoded links contain validated scene configuration.

ONE RENDERER

Immutable particle and curve geometry are generated once. GPU instancing and direct-time transforms update the scene in a few draw calls.

SMALL LINKS

Scene JSON is optionally gzip-compressed and base64url-encoded inside #scene=…. The server never sees the fragment.

PERCEPTUAL LOD

Automatic quality changes raster resolution only, not geometry or behavior. The reference uses explicitly chosen rendering conditions.

OPEN FORMAT

Versioned data validation and bounded resource limits. No JavaScript or shader source can be supplied through a URL.

This prototype implements one generator family, not arbitrary physical simulations or a general game engine. Runtime reproducibility within one environment does not imply cross-GPU bitwise identity.
