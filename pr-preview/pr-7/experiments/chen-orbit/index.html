The underlying system

The default mesh is extracted from a three-dimensional density field of 180,000 integrated trajectory samples. Gaussian neighbourhoods give the thin chaotic folds finite thickness; the equations determine every lobe, fold and opening. This numerical level set is not an invariant surface. Colour follows locally averaged trajectory speed.
