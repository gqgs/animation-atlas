What is being interpolated?

Each texture is a zero-mean stationary Gaussian field. Its covariance is diagonal in the Fourier basis, with power spectrum P(k).

For this scalar, commuting case, the Gaussian 2-Wasserstein path interpolates spectral amplitudes:

Hm = (1 − m) √PA + m √PB
Pm = Hm²
um = IFFT(Hm Z(t))

The same Gaussian Fourier realization Z(t) drives the path, with conjugate symmetry for a real field. A has two directional lobes; B has an isotropic low-pass spectrum. Spectrum amplitudes mix on fixed frequencies; frequency mass is not advected.

The comparison crossfades two independent Gaussian realizations before applying the same palette. Its power lacks the shared-noise cross term, so it loses more variance midway. With the same realization, an amplitude blend is also a linear blend of coupled fields; this is the optimal coupling, not a claim that every crossfade differs.

Translation plus smooth frequency-dependent phase modulation creates coherent motion. Coherence controls the rate and strength of the modulation. This is an artistic temporal extension, not the paper’s learned autoregressive dynamic model. During the morph the covariance changes in time.

The display applies a nonlinear color map to a scalar field; the colored pixels are not themselves Gaussian. Equal endpoint expected variance; no per-frame contrast normalization. Spectral thumbnail uses the analytic model power.
