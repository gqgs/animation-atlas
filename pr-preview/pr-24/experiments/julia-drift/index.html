Behind the spirals

Seeded inverse iteration, z → ±√(z − c), builds a cloud of nested Julia spirals. Branch bias changes how often each square-root branch is visited. A closed Möbius transformation moves that fixed cloud without resampling it each frame.

Inspired by Roger Bagula and Paul Bourke’s adjusted-probability reverse Julia. The default parameter is c = −0.75 + 0.10i. This study uses the genuine inverse quadratic map, with angle arg(z − c).

Zoom to explore the fine spirals; increase sample count for close crops. Extreme branch biases deliberately leave parts of the set sparse.
