What are we testing? / controls and limits

x″ + δx′ − x + x³ = γ cos(1.2t). Folding: δ=.2, γ=.30. Gentle: δ=.3, γ=.12. Fixed RK4 at 1/120 s; 100 s warm-up; 2.5 s exponential smoothing. x, velocity and energy control warp, shear and coverage. The phase trace is a diagnostic, never cloud geometry. “Folding” is a candidate irregular regime, not proof of chaos.

All views use the same seed, 5-octave field and shader; only macro control differs. Compare structural memory, distinctness and flicker at 1×, then inspect a minute at 10×. The sky is a 2.5D field, not a fluid or volumetric simulation. Timings are local measurements; GPU timing appears only when supported. Fixed pixel budgets, no raymarching.
