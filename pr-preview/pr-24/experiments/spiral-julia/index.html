Behind the spirals

Each pixel starts an orbit of z → tan(z² + c). Changing c rearranges the nested cells and spiral chains. This is an independent study inspired by Paul Bourke and Paul Nylander.

Colors record the first crossing of |z| > 2, capped at the chosen iteration count. For this tangent map, that threshold is a drawing convention, not proof that an orbit escapes forever. The palette background marks points with no crossing found within the cap.

The first two compositions use c = 2.0625 + 0.1425i and c = 1 − 0.38i. Motion returns to the exact parameter at the start of each loop. Choose Still to freeze it.
