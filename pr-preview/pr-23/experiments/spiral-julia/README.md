# Spiral Julia

An interactive study of `z → tan(z² + c)`, inspired by Paul Bourke and Paul Nylander. Open `index.html` through a local HTTP server or launch it from Animation Atlas.

- [Math, controls, and export](docs/math-and-controls.md)
- [Validation and limitations](docs/validation.md)

From the repository root: `node --test dist/experiments/spiral-julia/core.test.mjs dist/shared/frame-export.test.mjs`.
